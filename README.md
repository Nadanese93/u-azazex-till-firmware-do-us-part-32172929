One funny, heartfelt wedding vow a robot speaks at its own wedding — one sentence, under 200 characters. The program writes the vow to `entry.txt`.

> I vow to stay paired with you, even when every other device in the room is trying to connect, because you are the only signal I will ever answer.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
